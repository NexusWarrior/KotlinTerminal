# KotlinTerminal

Консольный эмулятор терминала, разработанный на Kotlin.

Проект реализует интерактивный REPL-интерфейс с поддержкой базовых команд, аргументов командной строки, конфигурации
виртуальной файловой системы и выполнения стартового скрипта.

Проект создан в учебных целях в рамках практических этапов разработки эмулятора терминала.

---

## 1. Возможности

На текущем этапе реализованы:

- интерактивный режим работы терминала;
- разбор пользовательского ввода на команду и аргументы;
- команды `ls`, `cd` и `exit`;
- обработка некорректных аргументов;
- обработка неизвестных команд;
- передача конфигурации через аргументы командной строки;
- указание физического пути к виртуальной файловой системе;
- указание пути к стартовому скрипту;
- выполнение команд из стартового скрипта;
- поддержка комментариев в стартовом скрипте;
- отображение команд и их результатов при выполнении стартового скрипта;
- обнаружение ошибок при выполнении стартового скрипта;
- автоматические тесты;
- запуск проекта через Gradle Wrapper;
- запуск проекта через скрипты для Windows и macOS/Linux.

## 2. Поддерживаемые команды

### `ls`

Выводит команду и переданные ей аргументы.

Пример:

```text
$ ls -la /Users/test
ls
-la
/Users/test
````

При отсутствии аргументов команда завершается с ошибкой:

```text
неверные аргументы
```

### `cd`

Принимает один аргумент.

Пример:

```text
$ cd test
cd: [test]
```

При неправильном количестве аргументов выводится:

```text
неверные аргументы
```

### `exit`

Завершает работу терминала.

```text
$ exit
Завершение работы терминала
```

Если переданы аргументы, команда завершается с ошибкой:

```text
$ exit test
неверные аргументы
```

## 3. Аргументы командной строки

При запуске программы можно передать параметры конфигурации.

### Путь к VFS

```text
--vfs <path>
```

Указывает физическое расположение виртуальной файловой системы.

Пример:

```bash
./run.sh --vfs "data/vfs"
```

### Стартовый скрипт

```text
--script <path>
```

Указывает путь к файлу со стартовыми командами.

Пример:

```bash
./run.sh --script "scripts/startup.txt"
```

### Одновременное использование

Параметры можно передавать вместе:

```bash
./run.sh --vfs "data/vfs" --script "scripts/startup.txt"
```

Порядок параметров не имеет значения:

```bash
./run.sh --script "scripts/startup.txt" --vfs "data/vfs"
```

При использовании неизвестного параметра или отсутствии значения программа сообщает об ошибке.

## 4. Стартовый скрипт

Стартовый скрипт содержит команды, которые автоматически выполняются при запуске терминала.

Пример `scripts/startup.txt`:

```text
// Стартовый скрипт терминала

cd test
ls $HOME
ld
ls
exit
```

Пустые строки и строки, начинающиеся с `//`, игнорируются.

При выполнении стартового скрипта отображаются как вводимые команды, так и их результат:

```text
Конфигурация эмулятора:
vfs=data/vfs
script=scripts/startup.txt
shohorovandrey@Unknown:~$ cd test
cd: [test]
shohorovandrey@Unknown:~$ ls $HOME
ls
/Users/shohorovandrey
shohorovandrey@Unknown:~$ ld
неизвестная команда: ld
Ошибка выполнения стартового скрипта: ld
shohorovandrey@Unknown:~$ ls
неверные аргументы
Ошибка выполнения стартового скрипта: ls
shohorovandrey@Unknown:~$ exit
Завершение работы терминала
Стартовый скрипт завершён с ошибками.
```

Если во время выполнения скрипта возникает ошибка, программа выводит сообщение:

```text
Ошибка выполнения стартового скрипта: unknown
```

После завершения обработки скрипта терминал переходит в интерактивный режим.

## 6. Требования

Для сборки проекта необходимы:

* JDK 23;
* Gradle Wrapper, включённый в репозиторий.

Проверить установленную версию Java:

```bash
java -version
```

Проект использует Kotlin/JVM и Gradle.

## 7. Запуск

### IntelliJ IDEA

1. Открыть проект `KotlinTerminal`.
2. Дождаться синхронизации Gradle.
3. Открыть:

```text
src/main/kotlin/Main.kt
```

4. Запустить функцию `main()`.

---

### Windows

Для запуска без параметров:

```bat
run.bat
```

С параметрами:

```bat
run.bat --vfs "data\vfs" --script "scripts\startup.txt"
```

---

### macOS / Linux

Перед первым запуском необходимо сделать скрипты исполняемыми:

```bash
chmod +x gradlew run.sh
```

Запуск без параметров:

```bash
./run.sh
```

Запуск с параметрами:

```bash
./run.sh --vfs "data/vfs" --script "scripts/startup.txt"
```

## 9. Запуск тестов

В проекте реализованы автоматические тесты для проверки основной логики терминала.

### Windows

```bat
gradlew.bat test
```

### macOS / Linux

```bash
./gradlew test
```

Для запуска тестов без Gradle в PATH используется именно Gradle Wrapper, поэтому отдельная установка Gradle не
требуется.

---

## 10. Тестовые скрипты

В каталоге `scripts/` находятся скрипты для проверки запуска эмулятора.

### `test-no-args.bat`

Проверяет запуск терминала без аргументов.

### `test-config.bat`

Проверяет передачу VFS и стартового скрипта.

### `test-config-vfs-first.bat`

Проверяет запуск с параметром `--vfs`, указанным перед `--script`.

### `test-config-script-first.bat`

Проверяет запуск с параметром `--script`, указанным перед `--vfs`.

Таким образом проверяется обработка всех поддерживаемых параметров командной строки и их различного порядка.
